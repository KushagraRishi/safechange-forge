# SafeChange

Hazard-aware change control for medical device software, built on Atlassian Forge for Codegeist 2026.

When a developer changes device software, SafeChange finds the hazards in the team's Confluence hazard log that the change touches. The Jira issue cannot reach Done until each of those hazards has a signed risk review and a passed, linked test. A Rovo agent explains the impact and drafts the risk note.

Work in progress. Full build and install steps are coming.
